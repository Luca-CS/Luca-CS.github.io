Quantitative finance

Option pricing lab

option-pricing-lab

Python library that prices European, American, Asian and barrier options under Black-Scholes, Heston, Dupire local volatility and stochastic local volatility (SLV), calibrated to SPX options.

  • Local volatility and SLV reprice the SPX surface within 10 bp of implied volatility, across nine maturities from two weeks to two years.
  • With the same vanilla prices, a one-year up-and-out call is worth 1.9% of spot under Black-Scholes and 3.5% to 4.7% under the other three models.
  • 76 tests compare each pricer with an independent reference: closed forms, a binomial tree, Reiner-Rubinstein for barriers.
  • Python
  • Monte Carlo
  • Heston
  • SLV
  • JavaScript

Quantitative finance

Time-series momentum study

timeseries-momentum-study

Momentum and mean-reversion signals tested on 10 assets, with daily prices from 2000 to 2025. Signals are selected on the training period only, with a Holm-Bonferroni correction, then backtested on the test period.

  • 9- to 12-month momentum does not hold out of sample.
  • A 2-month contrarian signal has a Sharpe ratio of 0.11 over 2018-2025, against 0.07 for an equal-weight portfolio.
  • A regime-switching extension (HMM) was tested and dropped: it did not find usable regimes.
  • Python
  • Jupyter
  • Backtest
  • HMM

Outlook bridge

outlook-bridge

Read-only MCP server that lets Claude read desktop Outlook (mail and calendar) through COM. It needs neither Microsoft Graph nor an app registration, so it also works on accounts where these are blocked.

  • A test fails if the code contains any call that could modify a mailbox.
  • Mail content is marked as untrusted, to limit prompt injection.
  • Over 350 tests, run against a fake Outlook.
  • Built with Claude Code from a specification and safety rules I wrote.
  • Python

  • pywin32

Windows tool

Disk Manager

disk_manager

Local storage manager for Windows: treemap, duplicate finder, cache cleanup sorted by risk, disk usage history.

  • No dependencies: Python standard library and a web interface with no build step.
  • No network access: the server listens on 127.0.0.1 only, with a strict CSP and a new token at each launch.
  • Deletions go to the recycle bin by default and only touch allow-listed caches, with protection against junctions and symbolic links.
  • Python
  • JavaScript
  • Windows

Machine learning · School project

EmotionLLM

EmotionLLM

A CNN on MFCC features labels the emotion of a voice recording (six classes, trained on IEMOCAP), Whisper transcribes it, and a small language model replies in a matching tone. CentraleSupélec project (ST7), March 2025, reworked in October 2026.

  • The first version loaded weights that did not match the network, so its emotion label was random. Retrained, with a test that loads the weights strictly.
  • On speakers never seen in training: 37% accuracy on six classes (chance: 17%). The reply only changes tone when the calibrated confidence is at least 0.45.
  • Runs locally on CPU: Whisper and Qwen2.5-1.5B through llama.cpp. 60 tests.
  • Python
  • PyTorch
  • Whisper
  • llama.cpp
