Quantitative finance

Time-series momentum: overfitting or robust signal?

timeseries-momentum-study

A momentum strategy studied on 10 assets with daily prices from 2000 to 2025. The protocol is built against overfitting: tests on the training period only, Holm-Bonferroni correction, backtest on the test period only.

  • Negative result, reported as such: 9-12 month momentum does not hold out of sample.
  • The 2-month contrarian signal reaches a Sharpe ratio of +0.11 over 2018-2025, against +0.07 for the equal-weight benchmark.
  • An HMM regime extension was tested and rejected: the regimes found are not usable.
  • Python
  • Jupyter
  • Backtest
  • HMM

LLM · MCP

outlook-bridge

outlook-bridge

A read-only MCP server that gives Claude access to desktop Outlook through COM. No Microsoft Graph and no app registration, so it also works on corporate or school accounts that forbid them.

  • Read-only enforced by a test that rejects any call able to change a mailbox.
  • Mail content labelled as untrusted, against prompt injection.
  • 350+ tests; the logic is tested without Outlook against a fake gateway.
  • I wrote the specification and the safety rules, then built it in phases with Claude Code.

Windows tool

Disk Manager

disk_manager

A fully local storage manager for Windows: treemap, duplicate finder, cache cleanup ranked by risk level, and disk usage history.

  • No dependencies: Python standard library and a web interface without a build step.
  • No network calls: server bound to 127.0.0.1, strict CSP, a random token on each launch.
  • Guarded deletions: recycle bin by default, allow-listed caches, protection against junctions and symbolic links.
